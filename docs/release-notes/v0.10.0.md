Death Counter is now **Byrgenwerth**, with two tools in one app and a macOS version.

Windows, in PowerShell:

```powershell
irm https://raw.githubusercontent.com/nguucode/byrgenwerth/main/install.ps1 | iex
```

macOS 14 or newer, in Terminal:

```bash
curl -fsSL https://raw.githubusercontent.com/nguucode/byrgenwerth/main/install.sh | sh
```

### Added
- **Translate**: draw a box around game dialogue and a Vietnamese translation appears next to it, in real time. Uses your own Anthropic API key. It is off each time the app opens; while on, the text in that box, the lines before it and the game name are sent to Anthropic. `Ctrl+Alt+T` turns it on or off, `Ctrl+Alt+R` redraws the box.
- **macOS version** with both tools. It is not notarized; the install command handles that.

### Changed
- New name and a new header: **Death count** and **Translate** at the top of the window.
- On Windows, an existing Death Counter install is renamed to Byrgenwerth and keeps its counts and settings. If OBS reads the text file, update its path.

### Not tried yet
Translation has not been tried on a real game, or against the live API. The macOS version has not been tried with a game, and this build's new Windows window has not been opened on a real PC. Please report what you find, with `ocr-debug.log` from the data folder.
