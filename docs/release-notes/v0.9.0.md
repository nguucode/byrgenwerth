### Install and update from PowerShell

```powershell
irm https://raw.githubusercontent.com/nguucode/death-counter/main/install.ps1 | iex
```

The first run asks for an install folder; run the same command again to update in place. The app shows up in the Start menu and in Windows *Apps & features*.
Manual install still works: download `DeathCounter.exe` below (SmartScreen may warn because the exe is not signed: *More info → Run anyway*).

### Changed
- **Data now lives in `DeathCounterData` next to `DeathCounter.exe`.** The data-folder picker is gone. Data from 0.8 (`%APPDATA%\DeathCounter` or the folder you picked) is copied over on first launch. Update the file path in OBS if you use the text-file source.

### Added
- **Uninstall** in the Cài đặt tab (or from *Apps & features*): removes the app, all its data, the shortcut and the registry entry. It cannot be undone.
- **F7** hides/shows the app window while you play. Detection, overlay and OBS keep running.

### Fixed
- Closing the app window hides it at once instead of hanging for a few seconds.
