macOS keeps the Screen Recording permission across updates from now on. The app itself is the same as v0.11.1.

Windows, in PowerShell:

```powershell
irm https://raw.githubusercontent.com/nguucode/byrgenwerth/main/install.ps1 | iex
```

macOS 14 or newer, in Terminal:

```bash
curl -fsSL https://raw.githubusercontent.com/nguucode/byrgenwerth/main/install.sh | sh
```

### Fixed
- macOS: after an update the app kept saying it had no Screen Recording permission, even with Byrgenwerth switched on in System Settings. Each build had a different signature, so the permission given to the old build no longer applied. The Mac app is now signed with the same certificate every time.

### Updating on a Mac
This one update asks for Screen Recording once more: the installer clears the old permission, then open the app, allow, and open it again. Later updates keep it.

If you installed by hand and Settings shows Byrgenwerth switched on while the app says it has no permission, run this in Terminal, then open the app and allow:

```bash
tccutil reset ScreenCapture com.nguucode.byrgenwerth
```
