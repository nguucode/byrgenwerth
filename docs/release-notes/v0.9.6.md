Fixed from a real Dark Souls Remastered log (`ocr-debug.log`):

### Fixed
- **Each death counted twice.** OCR counted the death, then about 16 seconds later a death-screen template matched a dark screen (the respawn, or a screenshot tool dimming the screen). Once OCR has read the death text in a session, a template match alone no longer counts. Template matches must again be on two frames in a row.
- **Death not credited to the boss.** OCR often reads the boss name cleanly only on the death screen. A death is now credited to a boss confirmed within 15 seconds after it, and a boss name needs about 5 seconds on screen instead of 10 OCR reads.
- **Wrong boss names.** Dark Souls Remastered's boss-name region now matches the real position (left end of the boss bar), so item labels like "Black Firebomb" stay out. Button prompts with a colon ("E : Rest at bonfire") are never boss names, and bosses are only read while a full-screen game is in front, not while a browser or chat window is.

### Added
- `ocr-debug.log` also writes why each automatic count happened.
