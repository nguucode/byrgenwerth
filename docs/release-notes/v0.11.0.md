Boss tracking is gone, so the app can focus on counting deaths well.

Windows, in PowerShell:

```powershell
irm https://raw.githubusercontent.com/nguucode/byrgenwerth/main/install.ps1 | iex
```

macOS 14 or newer, in Terminal:

```bash
curl -fsSL https://raw.githubusercontent.com/nguucode/byrgenwerth/main/install.sh | sh
```

### Removed
- Boss tracking: boss name reading, the Boss tab, the Top 3 panel on screen and the `/bosses` page for OBS. If OBS uses that page, remove the source; the main death count source keeps working.
- Per-boss stats are dropped the first time the app saves a game. To keep them, copy `profile.json` from the data folder before updating. Your total death count stays.

### Changed
- Turning OCR off now stops it completely. Before, it kept running to read boss names.

### Not tried yet
This build has not been opened with a game on either system, and the Windows window has not been opened on a real PC. Please report what you find, with `ocr-debug.log` from the data folder.
