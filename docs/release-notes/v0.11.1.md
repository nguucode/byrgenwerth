The install commands work again, and point at the repo's new name. The app itself is the same as v0.11.0.

Windows, in PowerShell:

```powershell
irm https://raw.githubusercontent.com/nguucode/byrgenwerth/main/install.ps1 | iex
```

macOS 14 or newer, in Terminal:

```bash
curl -fsSL https://raw.githubusercontent.com/nguucode/byrgenwerth/main/install.sh | sh
```

### Fixed
- Installing on macOS stopped with `curl: (56) The requested URL returned error: 504`. GitHub's direct release download link was answering 504; both install scripts now download through the GitHub API instead.

### Changed
- The repo is now `nguucode/byrgenwerth` (was `nguucode/death-counter`). Old links still redirect for now, but use the commands above from here on.
