First public release.

**Download `DeathCounter.exe` below and run it.** Windows 10/11, 64-bit. No installer.
SmartScreen may warn because the exe is not signed: *More info → Run anyway*.

### Features
- Automatic death detection with Windows OCR ("YOU DIED", "WASTED", "DEAD"...)
- Presets for 100 popular games (37 with verified death-screen text)
- Games without a death screen: counts when the health bar empties and the screen fades to black (HUD bars and on-character bars like Dead Space)
- Self-learning screenshot templates, F9 to teach any game
- Top 3 bosses that killed you, LiveSplit-style panel (on screen and OBS)
- On-screen overlay and OBS Browser Source with your text style
- Choose where data is stored
- Optional sound on every count (bring your own file)

Guides: [English](https://github.com/nguucode/byrgenwerth/blob/main/docs/user-guide.md) · [Tiếng Việt](https://github.com/nguucode/byrgenwerth/blob/main/docs/huong-dan-su-dung.md)

### Known limits
- Games must run Borderless or Windowed (not exclusive fullscreen).
- Boss tracking, OCR language selection and the health-bar detector are new and lightly tested.
